## 二、遍历与树的属性

核心：用某种遍历顺序访问节点，并在遍历中收集或计算树的属性（深度、路径和、可见节点、重建结构）。
这一类的第一个决策永远是：**信息是自顶向下传，还是自底向上返回？**

### 两种视角

| 视角 | 做法 | 典型代码形态 |
|---|---|---|
| 自顶向下（先序，「递」时带参数） | 把已知信息通过参数传给孩子 | `dfs(node, depth)` / `dfs(node, remain)` |
| 自底向上（后序，「归」时返回值） | 子树先算出结果，父节点再合并 | `return 1 + max(dfs(l), dfs(r))` |
| 层序（BFS） | 按层处理，每层是一个批次 | `for _ in range(len(queue))` |

### 四道题对比

| 题 | 难度 | 主要套路 | 信息流向 | 一句话 |
|---|---|---|---|---|
| [104. 二叉树的最大深度](104_maximum_depth_of_binary_tree.py) | 简单 | DFS（后序）/ BFS 数层数 | 自底向上返回 | `1 + max(左, 右)`；也可自顶向下带 `depth` 维护全局最大 |
| [112. 路径总和](112_path_sum.py) | 简单 | DFS 自顶向下 | 向下传「剩余目标值」 | 只在**叶子**处判断 `remain == node.val` |
| [199. 二叉树的右视图](199_binary_tree_right_side_view.py) | 中等 | BFS 取每层最后一个；或「右优先」DFS | 按层 / 按深度 | 每个深度第一次被访问到的节点（右优先）就是可见节点 |
| [105. 从前序与中序遍历序列构造二叉树](105_construct_binary_tree_from_preorder_and_inorder_traversal.py) | 中等 | 分治 + 哈希表 | 向下传区间 | 前序定根，中序定左右子树大小 |

### 各题特性与易错点

#### 104. 最大深度
- 最基础的「树的属性」题，空树深度为 0。
- 两种写法都要会：后序返回值（简洁）、自顶向下带参数（为后面的「带状态 DFS」打基础）。
- BFS 写法：层数 = 外层循环次数。

#### 112. 路径总和
- 易错点 1：必须是**根到叶子**。`[1,2]`, `target=1` 应为 False，因为 1 不是叶子。
- 易错点 2：不能在和超过 `target` 时剪枝——节点值可以为负。
- 易错点 3：空树直接 False，即使 `target == 0`。
- 叶子判断：`not node.left and not node.right`，不要只判断 `not node`。

#### 199. 右视图
- 本质是「每一层的最后一个节点」。
- BFS：记下每层 `len(queue)`，取该层最后一个。
- DFS：先右后左，`depth == len(res)` 时第一次到达该层，记录当前节点。
- 易错点：右子树不够深时，左子树更深的部分也会被看到，不能只沿右孩子走。

#### 105. 前序 + 中序建树
- 前序第一个是根；在中序里找到根的位置，左边是左子树，右边是右子树。
- 用哈希表 `val -> 中序下标`，把每次找根从 O(n) 降到 O(1)，整体 O(n)。
- 左子树大小 `left_size = root_idx - in_left`，据此划分前序区间；这是最容易算错的地方。
- 建树顺序要先左后右（前序消费顺序），否则指针对不上。
- 传下标区间而不是切片，避免 O(n²) 拷贝。

### 本类共性小结

- **题型识别**：问的是「整棵树的某个数」或「一组节点」，而不是修改树的形状。
- **写代码前先回答**：这个信息是从父传给子，还是从子传给父？
- **叶子 vs 空节点**：112 要求叶子判定，104 的终止条件是空节点，别混用。
